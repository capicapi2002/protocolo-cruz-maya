# protocolo-cruz-maya
Laboratorio de decodificación. A través de la bioneuroemoción y el rigor del Calendario Sagrado, transformamos la incertidumbre en un mapa estructural.Fusionamos el análisis del Nahual con el estudio de las improntas emocionales para brindar una herramienta reveladora y sanadora. Objetivo es el entendimiento de la propia arquitectura vital.
